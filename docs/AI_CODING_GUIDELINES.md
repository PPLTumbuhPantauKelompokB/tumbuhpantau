# Aturan AI Coding untuk TumbuhPantau

- Baca `docs/SDD.md` dan `docs/IMPLEMENTATION_PLAN.md` pada setiap sesi coding.
- Kerjakan **satu task kecil** per iterasi; jelaskan rencana terlebih dahulu bila mengubah database/arsitektur.
- React hanya mengelola presentasi; semua permission, scoping, dan validasi domain wajib di Express.
- Jangan menambahkan API klinis tanpa auth dan per-role organization scope.
- Jangan membuat perhitungan WHO dari tebakan/rumus yang tidak diverifikasi.
- Jangan menghapus revisi pengukuran lama atau audit aktivitas.
- Jangan menggunakan data anak nyata, NIK, kredensial, .env, data rumah, atau data pribadi dalam prompt, seed, screenshot atau commit.
- Catat dependency baru berikut alasan dan versi; jangan mengubah stack tanpa persetujuan.
- Buat test ketika logika bisnis ditambahkan; jangan mengatakan test lulus kecuali dijalankan dan ada hasil.
- Setelah coding, laporkan file berubah, command untuk testing, hasil aktual, kendala, dan TODO.
- Ikuti ketentuan tools AI di Bab 6 proposal atau keputusan resmi perkuliahan terbaru.
